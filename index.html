About the studio

How our ancestors survived, told with real evidence

Primer Fuego Studio researches, writes and produces documentaries about the Ice Age, early human species and the archaeological sites that changed what we know about ourselves. Each episode lists its scientific sources in the video description. Narration and visuals are made with AI tools and reviewed by the studio before publication; scenes with people are labelled as dramatised reconstructions.

Internal publishing tool

The studio uses a private, internal tool ("Primer Fuego Studio publisher") that runs only on the studio owner's computer. It uses the YouTube API Services to upload the studio's own original videos, set their titles, descriptions, thumbnails and playlists, and read the analytics of the studio's own channels. It has no public sign-up and no third-party users.

Privacy Policy

This policy explains what data the Primer Fuego Studio publishing tool ("the tool") accesses through the YouTube API Services and how it is handled.

Who uses the tool

The tool is used only by the owner of Primer Fuego Studio to manage the studio's own YouTube channels. It does not offer accounts, sign-up or access to anyone else.

Data accessed through YouTube API Services

  • Basic information about the studio's own channels (channel name and ID), to confirm which channel is connected.
  • Upload of the studio's own video files and their metadata: title, description, tags, category, language, thumbnail, playlist and publication schedule.
  • Aggregated analytics of the studio's own channels and videos: views, watch time, average view duration, subscribers gained, likes, comments and shares.

The tool does not access, collect or store personal data of viewers or of any other YouTube user.

How the data is used and stored

Analytics are saved as local files on the studio owner's computer and used only to decide which documentaries to produce next. OAuth access tokens are stored locally on that computer and are never shared. No data obtained through the YouTube API Services is sold, shared with third parties or used for advertising.

Retention and deletion

Locally stored analytics are kept for up to 24 months and then deleted. Access can be revoked at any time from the Google Account security settings at security.google.com/settings/security/permissions, after which the tool can no longer access the channels and its stored tokens stop working.

Google and YouTube

The tool uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
